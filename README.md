# Hashing-para-pesquisa-de-documentos
 Índice Invertido com Hash Aberto – Estruturas de Dados I (UFOP)
Este repositório contém a implementação de um índice invertido utilizando tabelas hash com endereçamento aberto como estrutura base. O projeto foi desenvolvido como parte do Trabalho Prático III da disciplina BCC202 – Estruturas de Dados I, ofertada pela Universidade Federal de Ouro Preto (UFOP) no semestre 2024/1.

🧠 Objetivo
Construir um índice invertido a partir de um conjunto de documentos e permitir:

Consultas por palavras-chave para identificar documentos relevantes.

Impressão do índice invertido, com base na ordem de inserção das palavras na hash.

🗂️ Funcionalidades
- Inserção de documentos e palavras-chave em estrutura de hash aberta.
- Consulta por termos e retorno dos documentos correspondentes, ordenados lexicograficamente.
- Impressão do índice invertido conforme ordem da tabela hash.
- Quantidade de documentos.
- Nome dos arquivos e suas palavras-chave.
- Comando (B para busca ou I para impressão do índice)
- Palavras a serem buscadas (caso opção seja B).
